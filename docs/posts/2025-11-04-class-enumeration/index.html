Impact of estimation algorithm on class enumeration

research

A case study

Jessica
11-04-2025

Introduction

For my master’s thesis I was interested in comparing the performance of two estimation algorithms for latent class models: Newton Raphson (NR) and Expectation-Maximization (EM). EM is the most common estimation algorithm, although there are hybrid algorithms that combine the two. I was inspired by a paper from Chen et. al (2020) , where the authors did a similar comparison through a simulation study and found that certain derivative based methods (sequential quadratic-programming and projected quasi-newton) tended to find better log-likelihood (LL) solutions compared to EM. Since the second year of my PhD program I have been interested in derivative based estimation algorithms. Their procedure has always been more intuitive to me compared to EM, but more importantly I found that their utility has been underexplored in the context of latent class models. Since the likelihood surface for mixture models is so complicated, with many local minima, it is important to make sure that we have adequately explore the parameter surface. Examining the estimation algorithm is one way to do that, along with comparing different methods for generating start values.

From my master’s thesis I found that occasionally NR converged to a better maximum LL solution compared to EM when data conditions were subpar- small sample sizes, high measurement error in item parameters, and unbalanced latent class prevalences (one class describes a large portion of the sample while other classes are small).One flaw in my study was that I only fit the correct number of classes. In my simulation study the true number of classes across all conditions was 4, and I only attempted to fit 4 classes for all of the datasets due to time constraints. However, outside of simulation studies the true number of classes is never known. Normally a range of classes of fit (first fitting one class, then two classes, etc.) and the optimal number of classes is chosen based on a combination of fit criteria (BIC/AIC), likelihood ratio tests, and theoretical relevance. If a class structure truly exists in the data, then one will definetly fit the wrong number of classes at some point. An unanswered question I had after completing my masters was how do NR and EM compare when fitting the incorrect number of classes? If they can differ in the final solution when fitting the correct number of classes, then it is likely that they may also differ in all other scenarios.

For EM there was a noticeable pattern of increasing unique solutions as the number of classes increased. For NR there is another aspect to consider! As shown below, the convergence rate decreased drastically as the number of classes increased. NR has a stricter convergence criteria compared to EM that relies on the value of the gradient to achieve convergence, hence the low values. At 5 classes only 20 out of 500 iterations converged. This means that if one were to use NR, it would be advisable to increase the number of iterations.

Class Enumeration

Choosing the optimal number of classes is a crucial component to latent class analysis that has been well-researched! As I mentioned earlier the process of choosing the number of classes depends on multiple factors, but here I will focus on information-criteria because it is directly tied to the likelihood. Akaike information criterion (AIC) and Bayesian information criterion (BIC) are relative fit indices calculated based on a combination of the the likelihood and other factors. BIC is dependent on the number of parameters estimated and sample size and tends to perform better with larger sample sizes (Morgan et. al, 2015), while AIC is calculated using the number of parameters and not sample size. The best model in terms of these indices is the one with the lowest AIC and BIC values. AIC and BIC values for the models fit in this analysis are shown in the two tables below.

Apart from the 3 class model, the BIC and AIC values for each class are the same across the two algorithms. It is only the 3 class model where the AIC and BIC values differ between NR and EM, due to differences in the maximum LL solution reached. For BIC it ultimately does not matter because the optimal number of classes according to both NR and EM is 2. However, for AIC NR points to 3 classes being optimal, while AIC points to 2 classes. This discrepency highlights the importance of algorithm choice! If we only ran NR we may choose 3 classes as our final solution (pending consideration of other criteria), while if we only ran EM we may choose 2 classes.

Conclusion

Although this is just a case study using one simulated dataset, I think the results have important implications. The choice of algorithm has been largely overlooked in empirical analysis using latent class models, creating an implicit assumption that the same (“global”) likelihood solution will be reached regardless of estimation algorithm used. The results here show that that is not necessarily the case, and the consequences of ignoring algorithm choice can possibly even lead to a different number of classes chosen if we use information-criteria. In an ideal world I would recommend researchers to use two different algorithms (not necessarily NR) and compare the maximum LL results. The interpretation of the classes and the validity of the model rests entirely on the parameter estimates, so it is important to make sure we have explored the parameter space as thouroughly as possible. In the future I would like to repeat this analysis but with empirical data!
